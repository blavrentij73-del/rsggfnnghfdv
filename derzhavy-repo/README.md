# Державы — карта мира

> Браузерная стратегия на карте мира в одном HTML-файле. Без сборки, без зависимостей, без сервера.

«Державы» — пошаговая стратегия, где вы управляете государством на интерактивной карте мира: развиваете провинции, добываете ресурсы, изучаете технологии, заключаете союзы, создаёте вассалов и унии, ведёте войны и переносите столицу.

## Возможности

- **Карта мира**: около 1800 провинций и 190+ держав на растре 2100×1425, флаги рисуются кодом.
- **Сценарии**: 1444, 1600, 1815, 1914, 1939 и 2026 год — от эпохи открытий до современности.
- **Ресурсы провинций**: 12 типов (зерно, скот, лес, меха, железо, уголь, самоцветы, золото, соль, рыба, вино, кони). Влияют на доход, стоимость построек и найма, силу кавалерии и волнения. Назначение детерминировано seed'ом партии.
- **Рельеф**: равнины, леса, холмы и горы — влияют на доход, оборону и набор ресурсов.
- **Экономика**: казна, доход, торговля с соседями, содержание войск и построек, развитие провинций, строительство (поля, рудники, мануфактуры, крепости, казармы), найм пехоты, кавалерии и артиллерии.
- **Древо технологий**: 5 веток по 3 технологии — хозяйство, военное дело, управление, флот, культура. Открываются последовательно, дают бонусы к доходу, армии, осадам, флоту и порядку.
- **Политика**: союзы, вассалы (дань 15% и участие в войнах), личные унии (10% дохода, совместные войны, присоединение через 2 года), пакты о ненападении, войны, мир, аннексия вассалов.
- **Столица**: переносится в любую свою неоккупированную провинцию; флаг и подпись переезжают вместе с ней.
- **Флот**: морские переброски, патрули, блокады, десант.
- **Достижения, летопись, режим наблюдателя, автосохранение** каждый январь и три ручных слота.
- **Цвета соседей** подобраны так, чтобы минимальное различие в Lab (ΔE) было не меньше 50.

## Запуск

Самый простой способ — открыть `index.html` в браузере (Chrome, Edge, Firefox). Игра полностью автономна.

Если браузер ограничивает `localStorage` для `file://`, запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000

## Управление

- **Мышь**: щелчок по провинции — выбрать; перетаскивание — двигать карту; колесо или кнопки `+`/`−` — масштаб.
- **Вкладки справа**: «Провинция», «Держава», «Мир», «Армия», «Наука», «Цели», «Хроника».
- **Армии**: выберите армию в разделе «Армия», затем щёлкните соседнюю провинцию — отдадите приказ о походе.
- **Сохранения**: «Держава» → «Сохранения». Автосохранение — каждый январь (ключ `derzhavy_save` в localStorage). «Новая партия» стирает автосохранение.

## Технологии

- Чистый JavaScript (ES2015+), Canvas 2D, CSS — без фреймворков и сборки.
- Данные карты: [Natural Earth](https://www.naturalearthdata.com/) (admin-1, реки, озёра) — public domain.
- Вся карта зашита в `index.html` (base64), поэтому файл весит около 8,3 МБ.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub, например `derzhavy`.
2. Загрузите файлы:

```bash
cd derzhavy-repo
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/derzhavy.git
git push -u origin main
```

3. Включите Pages одним из способов:

**Вариант А — из ветки.** Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
Сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/derzhavy/`.

**Вариант Б — через Actions.** Settings → Pages → Source: *GitHub Actions*. Workflow `.github/workflows/pages.yml` уже в репозитории и будет публиковать игру при каждом пуше в `main`.

Через минуту-две игра будет доступна по ссылке из раздела Pages.

## Ограничения

- Один файл на 8,3 МБ — на медленном соединении первая загрузка заметна.
- Сохранения живут в `localStorage` и привязаны к домену; переноса между устройствами пока нет.
- Мультиплеера нет, баланс и ИИ находятся в развитии.
